# ZikWall changes

## 0.1.0 preview — 12 October 2026

Added scoped production-broker throughput diagnostics with alternating off/on
loopback transfers, verified blocking and cleanup. Clarified monitoring-only
startup status; recorded raw speed and resource measurements with their limits.

Right-click actions on apps, subprocesses, connections and activity events, with
reviewed app/endpoint blocking, optional expiry, executable inspection, file
location, and copy actions. Windows and model checks cover stable targeting
through refresh and canceling block review without changes.

Windows 11 WinUI connection monitoring, expandable app/process groups, offline
country map and flags, recent alerts, tray and sign-in startup, experimental
observed traffic totals, and a separate Windows SDK session firewall broker.

See docs/FEATURE-STATUS.md for validation limits. Historical upstream release
notes are preserved under docs/upstream; they are not ZikWall releases.
