# Current UI screenshots

Captured from the current WinUI 3 source on 13 October 2026. These are native XAML renders, not design mockups. All connection endpoints use documentation address ranges and example.net names; history and traffic amounts are illustrative. App icons come from locally installed executables, with the normal fallback when one is unavailable.

After building the desktop app, run:

```powershell
.\artifacts\ZikWall\ZikWall.exe --test-readme-screenshots
```

The diagnostic writes six PNGs to `artifacts/ZikWall/readme-screenshots` and a result to `artifacts/ZikWall/readme-screenshots.txt`. It pauses monitoring, loads sample data in memory, renders Connections, My activity, and Log analysis in both themes, and exits without applying firewall policy. Review the images before copying them here.

WinUI's offscreen renderer excludes compositor Mica and Windows caption buttons. The diagnostic uses the theme's neutral background for these captures; the normal app continues to use its native backdrop.

`setup-dark.png` comes from the setup diagnostic generated by `tools/build-setup-exe.ps1`. It shows the update flow for package 0.10.18443 with an older build installed. The diagnostic does not perform an installation.
